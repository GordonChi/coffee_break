# coffee_break

## Description
This website made using the MERN stack, implementing skill learned and applying them to a
live site.



## Packages used
### Frontend
- reach-router-dom

### Backend
- bcryptjs - used for salting/hashing passwords
- mongoose - used for schema definitions
- speakeasy - 2FA code generation
- qrcode - 2FA QR code generation
- express - backend routing
